# Formax

Formax adalah aplikasi pembuat formulir berbasis web dan mobile yang memungkinkan pengguna membuat, mengelola, dan membagikan formulir digital secara mudah. 

Aplikasi ini dirancang untuk berbagai kebutuhan seperti survei, pendaftaran, kuis, absensi, hingga pengumpulan data umum lainnya.

---

## Fitur Utama

- Dynamic Form Builder: Membuat formulir dengan berbagai tipe input secara fleksibel.
- Easy Sharing: Membagikan formulir dengan cepat menggunakan tautan (link) atau kode QR.
- Response Management: Mengelola dan menganalisis hasil respon pengisian formulir.
